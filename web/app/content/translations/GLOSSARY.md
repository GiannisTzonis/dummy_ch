# Translation glossary (fr / it / de / es)

Every translation (interface wording and page text) uses these terms. Translate from the English;
when the English is unclear, the Greek page is the tie-breaker. Do not invent facts, soften or
embellish: same meaning, same facts, natural wording in the target language.

## Names: never translated

- People, choirs, ensembles, venues abroad, works, festivals and organisations abroad keep the
  spelling of the English page (Latin script): "Ambrož Čopi", "Vox Humana", "Voci Contra Tempo",
  "Gøtu Kirkju Ungdómskór", "Choral Festival Network (CFN)", "Ave Maria".
- Greek people and Greek choirs: the Latin spelling used on the English page ("Kosmas Koronaios",
  "Theodora Pavlovitch"), never re-transliterated.
- Titles of musical works stay as written (also when they are English).
- Greek towns: the usual name in the target language where one exists (Athènes / Atene / Athen /
  Atenas; Thessalonique / Salonicco / Thessaloniki / Tesalónica), otherwise the English spelling
  (Preveza, Nikopolis, Parga).

## Form

- Dates, times, numbers and scores exactly as in the English, written the target language's way:
  "6–12 July 2026" -> "6–12 juillet 2026" / "6–12 luglio 2026" / "6.–12. Juli 2026" /
  "6–12 de julio de 2026"; times as in the English ("10:00", "8:30 p.m." -> "20h30" / "20:30" /
  "20:30 Uhr" / "20:30"). Prices "€20" -> "20 €" (fr, de, es), "20 €" (it).
- Ordinals: "44th" -> "44e" / "44°" / "44." / "44.º".
- Headings, labels and buttons: the target language's usual capitalisation (French and Italian:
  sentence case; German: nouns capitalised; Spanish: sentence case). A label printed in capitals in
  the English stays in capitals.
- Formal address to visitors: vous / Lei (or impersonal) / Sie / usted.
- Keep markdown exactly: `[text](link)` (translate the text, never the link), `**bold**`, line
  breaks. Keep every block: one translated block per English block, in the same order.
